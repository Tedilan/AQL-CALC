검사특성곡선 (OC Curve, Operating Characteristic Curve)

핵심 수식 및 통계품질 이론 요약

1. 합격(Ac) 및 불합격(Re) 판정 조건

표본 크기 n 중 발견 결점수 d에 대해:

• 합격 (Acceptance): d ≤ Ac

• 불합격 (Rejection): d ≥ Re (보통검사 1회 기준 Re = Ac + 1)

2. 화살표 표기 규칙 (Arrow Rule)

• 아래 화살표 (↓): 화살표 바로 아래의 첫 번째 샘플링 방식 채택 (표본 크기 n도 변경된 행의 값 적용)

• 위 화살표 (↑): 화살표 바로 위의 첫 번째 방식 채택 (표본 크기 n도 해당 행의 값 적용)

• 표본 크기 n ≥ N(로트 크기)일 경우 100% 전수 검사 수행

3. OC 곡선 포아송 누적 확률 모델

불량률이 p일 때 합격확률 P_a(p) 계산 공식 (λ = n · p):

P_a(p) = \sum_{k=0}^{Ac} \frac{e^{-np} (np)^k}{k!}

AQL 지점에서 생산자 위험 α ≈ 0.05 (합격확률 약 95% 보장)
